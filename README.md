# 📱 手机事件感知器 (astrbot_plugin_event_sensor)

基于 iOS / Android 手机端自动化事件上报（如打开某个 App）与远程智能拦截，实现大模型角色自然抓包、拦截弹回与情感互动的 AstrBot 插件。

---

## 🌟 核心功能

1. **🌙 晚安装睡抓包**：在对话中捕捉到晚安/睡觉关键词后自动激活装睡陷阱。如果在设定时间内偷玩手机（如打开小红书、抖音等），会被当场抓包并自动切回聊天软件。
2. **💬 超时未回复（已读不回）抓包**：Bot 发送消息后，若用户超过设定时间未回复却偷偷刷手机，会触发吃醋/抓包互动。
3. **☕ 告别豁免机制**：用户声明去忙、去吃饭或明确表示去玩手机时，进入自然告别豁免期，不会误判抓包。
4. **🔒 实时拦截响应**：支持快捷指令接收判定结果，一旦触发抓包即可自动将手机切回聊天软件。

## 📲 iOS 快捷指令「抓包与自动切回」配置指南

### 第一步：创建自动化
1. 在 iPhone 上打开 **「快捷指令」** App。
2. 底部切换到 **「自动化」** -> 点击右上角 **「+」** 创建个人自动化。
3. 选择 **「App」**：
   - App：选取你要监控的应用（如 `小红书`、`抖音`、`Bilibili` 等）
   - 条件：勾选 **「打开时」**
   - 运行方式：勾选 **「立即运行」**，并**关闭**「运行时通知」
4. 点击下一步，选择 **「新建空白自动化」**。

---

### 第二步：添加操作动作

按顺序添加以下三个动作：

#### 1. 获取 URL 内容 (POST 上报事件)
- 添加操作：**「获取 URL 内容」**
- **URL**：`http://你的服务器IP:8788/api/sensor/event`
- 点击展开详细设置：
  - **方法**：`POST`
  - **头部**：
    - 添加新头部：键为 `X-Sensor-Token`，值为你在插件后台配置的 `auth_token`
  - **请求体**：选择 `JSON`
    - 添加字段：键为 `app_name`，类型为 `文本`，值为当前监控的 App 名称（如 `小红书`）
    - （可选）添加字段：键为 `event`，类型为 `文本`，值为 `blocked_app_opened`

#### 2. 如果 条件判断 (识别抓包状态)
- 添加操作：**「如果」**
- 点击输入项「如果」后面的蓝色标签：
  - 选择 **「URL 的内容」**
  - **点击该绿色标签展开**，将「类型」修改为 **「文本」**
- 条件选择：**「包含」**
- 后面输入框填入：`"locked":1`（⚠️ **注意**：冒号后**不要**加空格，必须严格写为 `"locked":1`）

#### 3. 打开 App (触发强行弹回)
- 添加操作：**「打开 App」** -> 选取 **「QQ」**（或你的聊天软件）
- 将「打开 App」操作**拖动到「如果」和「否则」的正中间**。

---

### 示例逻辑结构图

```text
获取 http://服务器IP:8788/api/sensor/event 内容 (POST, 带 Token, JSON: {"app_name": "小红书"})
如果 URL的内容(文本) 包含 "locked":1
    打开 QQ
否则
结束如果
```

> 💡 **提示**：配置完成后，只要在聊天中说完晚安并超过 30 秒（防误触缓冲期），一旦偷偷打开小红书，就会被瞬间强制切回 QQ，同时角色会触发抓包专属对话！

## ⚙️ 插件后台配置项说明

在 AstrBot 管理面板中可自由调节：
- `auth_token`：接收端密钥（需与快捷指令中的 `X-Sensor-Token` 一致）。
- `listen_port`：监听端口（默认 8788，需在服务器防火墙/安全组放行 TCP）。
- `active_start_time` / `active_end_time`：默认互动时间段。
- `trigger_keywords`：装睡抓包激活关键词（如 `老公晚安,晚安,睡觉了,去睡了`）。
- `dialogue_end_keywords`：告别豁免关键词（如 `去玩手机,先去忙了,去洗澡,去吃饭,拜拜`）。
- `enable_unreplied_trigger`：是否开启超时未回复抓包。
- `enable_force_redirect`：是否开启抓包强制切回/弹回（控制快捷指令是否执行强行打开QQ）。
- `unreplied_threshold_minutes`：未回复判定阈值（分钟）。
- `cooldown_minutes`：抓包防刷冷却时间（分钟）。
