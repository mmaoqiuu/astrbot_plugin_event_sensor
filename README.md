# 📱 手机事件感知器 (astrbot_plugin_event_sensor)

基于手机端自动化事件上报（如打开某个 App）与 AstrBot 对话上下文联动，实现角色自然抓包、即时唤醒与智能情感互动的插件。

---

## ⚠️ 使用注意事项（重要）

- **首次使用或修改配置后**：在面板修改配置或重启 Bot 后，**需要先在聊天窗口里发送任意一条消息与 Bot 对话一次**。
  - **原因**：Bot 需要在收到你的消息时获取当前私聊/群聊的会话目标（Session ID）。只有建立过一次对话后，后续手机端上报事件时，Bot 才能精准地将抓包消息推送到你当前的聊天窗口中。

---

## 🌟 核心机制与关键词配置

### 1. 🌙 睡意/装睡抓包触发关键词 (`trigger_keywords`)
- **默认关键词**：
  - `老公晚安`、`晚安`、`睡觉了`、`去睡了`、`睡觉觉`、`做梦去啦`
- **工作机制**：
  - 对话中一旦捕捉到上述关键词，系统会立即激活**「夜间装睡抓包模式」**。
  - **跨时段生效**：即使当前还没到预定的常规互动时间（例如在凌晨 00:30 互道晚安，而设定互动时间是 08:00~23:30），也会立刻开启感知。
  - **抓包保护与结束**：夜间装睡抓包最多持续 5.5 小时；或者一旦到了早上设定的常规互动时间，装睡抓包状态会自动结束。
  - **抓包判定**：如果在晚安后 30 秒至 5.5 小时内偷偷在手机上打开应用，角色会结合《小狗守则》自然进行抓包质问与调侃。

---

### 2. ☕ 告别/暂离豁免关键词 (`dialogue_end_keywords`)
- **默认关键词**：
  - `去玩会儿手机`、`去玩手机`、`玩会手机`、`先去忙了`、`去忙了`、`去洗澡`、`去吃饭`、`出门了`、`先下了`、`拜拜`
- **工作机制**：
  - 当你在对话中明确说明去忙/去玩手机/告别时，系统会判定对话进入**「预期内的正常收尾」**。
  - **豁免保护**：即使超过了设定的未回复时长（如 30 分钟），打开手机应用也**不会**触发“已读不回抓包”，避免误伤。
  - **解除机制**：当你下一次重新主动发送新消息开启新对话时，豁免状态会自动重置。

---

### 3. 💬 对话即时热配置（无需重载）
支持直接在聊天中对角色下达调整指令，角色会调用工具立即热更新并生效：
- “帮我把抓包互动时间改成早上 08:00 到晚上 23:30”
- “把防刷冷却时间改成 15 分钟”
- “把未回复抓包时长改成 45 分钟”
- “把触发关键词加上'困困'”
- 发送 `/抓包关键词` 可直接查看当前关键词与配置状态。

---

## ⚙️ 插件面板配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `auth_token` | 字符串 | 自动生成 | 手机端上报鉴权密钥（请求头 `X-Sensor-Token`） |
| `listen_port` | 整数 | `8788` | 事件接收端监听端口 |
| `active_start_time` | 字符串 | `08:00` | 常规互动开始时间 (HH:MM) |
| `active_end_time` | 字符串 | `23:30` | 常规互动结束时间 (HH:MM) |
| `trigger_keywords` | 字符串 | `老公晚安,晚安,睡觉了...` | 提前临时激活抓包的关键词列表 |
| `dialogue_end_keywords` | 字符串 | `去玩会儿手机,先去忙了...` | 告别/暂离豁免已读不回的关键词列表 |
| `enable_unreplied_trigger`| 布尔 | `true` | 是否启用超时未回复抓包 |
| `unreplied_threshold_minutes`| 整数 | `30` | 超时未回复判定时长（分钟） |
| `cooldown_minutes` | 整数 | `0` | 防刷触发冷却时长（分钟） |
| `prompt_keyword_catch` | 字符串 | 默认通用模板 | 晚安/装睡抓包注入的提示词模板（支持 `{minutes}`, `{text}`, `{keyword}`, `{app_name}` 占位符） |
| `prompt_unreplied_catch` | 字符串 | 默认通用模板 | 超时未回复抓包注入的提示词模板（支持 `{minutes}`, `{app_name}` 占位符） |
